# 2026-09-28

## CC98 Ocean —— 修复 CMAKE 错误并在 Windows 启动调试

**任务**:`flutter build windows` 报 CMake 错误,修好后在 Windows 上跑起 debug。

### 排查出的故障链(逐个串起来的,修一个才暴露下一个)

1. **`CMake Error ... Generator Visual Studio 16 2019 could not find any instance of Visual Studio`**
   本机只有 Visual Studio Community 2026(主版本 18),Flutter 3.32.8 的
   `packages/flutter_tools/lib/src/windows/visual_studio.dart` 中 `cmakeGenerator` 只映射到 17,
   18 掉进默认分支 `'Visual Studio 16 2019'`。
   → 补 `18 => 'Visual Studio 18 2026',`,并补 `_requiredComponents` 的 17/18 文案分支。

2. **工具快照必须手动失效**:`bin/internal/shared.bat` 的 compilekey 只取 git HEAD + FLUTTER_TOOL_ARGS,
   不感知源码改动。删 `bin/cache/flutter_tools.snapshot` + `flutter_tools.stamp` 后 `flutter --version` 重建。

3. **`media_kit_libs_windows_video` 依赖下载被截断**(0 字节 → Integrity check failed)。
   CMake 的 `file(DOWNLOAD)` 在受限网络下静默失败。用
   `curl -L --ssl-no-revoke`(不加这个会报 `CRYPT_E_NO_REVOCATION_CHECK 0x80092012`)手动下到
   `build/windows/x64/`,两个包 `mpv-dev-x86_64-20230924-git-652a1dd.7z`(MD5 a832ef24b3a6ff97cd2560b5b9d04cd8)
   和 `ANGLE.7z`(MD5 e866f13e8d552348058afaafe869b1ed)都已校验通过。

4. **MSVC 14.51 把 `<experimental/coroutine>` 升级为硬错误** `error C2338: STL1011`,
   `audioplayers_windows` 通过 C++/WinRT 间接引入。
   → 在 `windows/CMakeLists.txt` 的 `add_definitions(-DUNICODE -D_UNICODE)` 后加
   `add_definitions(-D_SILENCE_EXPERIMENTAL_COROUTINE_DEPRECATION_WARNINGS)`
   (必须在 `include(flutter/generated_plugins.cmake)` 之前,插件子目录才会继承)。

5. **INSTALL 失败 `MSB3073` → 实为 `file INSTALL cannot copy file ... to "C:/Program Files/cc98_ocean" : Permission denied`**。
   属 CMake 缓存毒化:模板里 `include(generated_plugins.cmake)` 排在安装前缀 `if` 之前,
   第一次 configure 在第 3 步中断时默认前缀已进缓存,`CMAKE_INSTALL_PREFIX_INITIALIZED_TO_DEFAULT`
   之后恒为 FALSE,前缀再也不修正。
   → ① 清空 `build/windows/x64` 后一次性跑通;② 把守卫改成
   `if(... OR CMAKE_INSTALL_PREFIX STREQUAL "C:/Program Files/${PROJECT_NAME}")` 防止再次毒化。

### 结果

- `flutter build windows --debug` 通过,产物 `build/windows/x64/runner/Debug/cc98_ocean.exe` + 全部插件 DLL + `data/`。
- `flutter run -d windows --debug` 启动成功,VM Service `http://127.0.0.1:52441/`,DevTools `http://127.0.0.1:9101`。
- 截图确认真实渲染:登录页(CC98 Ocean / 欢迎回家 / 昵称 / 密码 / 登录 / 文档·主页)正常。

### 遗留

- 改动了 Flutter SDK 源码(`visual_studio.dart`),`flutter upgrade` 会覆盖,需重新打补丁。
- `build/windows/x64/*.7z` 被 `flutter clean` 清掉后需要重新下载(网络受限时用 curl 手动下)。
- 截图工具留在 `build/cc98_debug.png` 和 `build/shot_cc98.py`(build/ 已被 gitignore)。
